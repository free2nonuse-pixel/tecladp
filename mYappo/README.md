# LinguaKey — Teclado Android con Traducción por IA

LinguaKey es una aplicación nativa de teclado para Android (basada en `InputMethodService`) que traduce en tiempo real de **español a inglés** con perfiles de informalidad adaptativos y **coste de uso de 0 dólares** utilizando modelos gratuitos de OpenRouter o Gemini.

## Características Principales

1. **7 Perfiles de Informalidad**:
   - Formal (Profesional / Trabajo)
   - Natural (Cotidiano / Fluido)
   - Casual (Relajado con contracciones)
   - Informal (Espontáneo y coloquial)
   - Internet (Chat online con 'ngl', 'fr', 'idk', 'lol' contextual)
   - Gamer (Glosario gaming: gg, AFK, nerf, buff, clutch, diff)
   - Personalizado (Instrucciones definidas por el usuario)
2. **Modo de Coste Cero**:
   - Bloqueo proactivo de cualquier modelo con precio mayor a 0$ o desconocido.
3. **Seguridad y Privacidad**:
   - Android Keystore + EncryptedSharedPreferences (AES-256).
   - Sin servidores propios intermedios.
   - Sin rastreo ni telemetría.
